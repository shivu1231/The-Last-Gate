# The Last Gate

The complete browser experience: Hiro returns through an unstable portal for Baymax, restores his damaged systems, finds the Bay 6 regulator, follows the healthcare chip signal, and brings Baymax home.

Built with React, TypeScript, Vite, Three.js, React Three Fiber, Zustand and GSAP. This repository contains the website source, public assets and compiled static site. It excludes development handoffs, recordings and local dependencies.

## Run

Use Node.js 22.12 or later.

```sh
npm ci
npm run dev
```

Development opens on http://127.0.0.1:4173. On an occupied port, use `npx vite --host 127.0.0.1 --port 4177 --strictPort`.

```sh
npm run check
npm run build
npm run preview
```

Deploy the contents of `dist/` to a static host. `node server.mjs` also serves the included build on port 4173 without installing dependencies.

## Controls

The opening advances automatically. Hold W, Space or the mouse to walk/sprint; use the on-screen controls for interactions. E guides the opening chip interactions. Later engineering, Bay 6 and telemetry controls explain the required action. The regulator remote and dragging interactions are available on screen. The sound toggle works throughout.

## Models and animation

The canonical Baymax shell supplies one closed body and shared chip bay. Combat colour/materials blend onto this same geometry; the healthcare state returns it to white. The regulator, remote, hands, Hiro, chips, engineering assemblies and environments are generated by the source factories. Authored motion and camera paths remain in the runtime.

`npm run models` exports the current characters, props and complete environment sets to `artifacts/models/`, with embedded textures, baked combat finish, a manifest and glTF validation report. Set `LAST_GATE_MODELS_OUT` to choose a different output folder. Exports are static scene/rig snapshots; runtime shaders, particles, choreography and gameplay are retained in this repository. The original source GLB is included in the collection. The retired separate armour asset remains credited in `public/models/baymax-armoured.CREDITS.txt`; the canonical live actor uses the shared shell.

## Verification

```sh
node scripts/later-refinement-check.mjs
node scripts/later-refinement-check.mjs scripts/opening-refinement-check.ts
```

Checks cover actor ground contact, regulator mount, recovery pose, camera routes, impact expiry, DPR logic and opening attack cadence/framing at wide/compact aspects and simulated 30/60Hz. These checks do not establish GPU performance parity across machines.

Development shortcuts include `?phase1=fight`, `?recovery=journey`, `?phase4=bay`, `?phase5=limiter`, `?phase5=facility`, and `?phase6=wake`, `escape`, `gate`, `drop`, `portal` or `home`. Production always starts the normal experience.
